The bluepilot team has been working hard on firmware modifications to enhance the capabilities of the Ford ADAS systems. The first item that has been addressed is the removal of the LKA timeout and minimum speed requirements so that the signals can be used 100% of the time. A huge shout out to Zorro and Cone_Guy for their work on this. The process involves extracting the PSCM Firmware using the beta version of Forscan, editing the firmware using an AI Agent coding assistant, and then flashing the modified files back via Forscan. So far this has only been successfully executed on a single vehicle (2025 Ford Transit), but the process should be applicable to all CAN (Q3) vehicles. 

Currently, this work is considered a proof of concept that needs further development, and the bluepilot team does not have the resources to commit to the effort. You may contribute to the effort by making a pull request against the seed work. in GitHub at:

https://github.com/ghostdev137/ford-pscm-re/tree/main
